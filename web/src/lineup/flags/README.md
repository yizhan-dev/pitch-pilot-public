# Flags

From flag-icons 7.2.3 (https://github.com/lipis/flag-icons, `flags/4x3/`, MIT licence in `LICENSE-flag-icons.txt`),
downloaded 2026-10-23 from cdn.jsdelivr.net, unchanged. Yi asked for proper flags in place of the hand-drawn ones (the
Welsh dragon was too simplified). Files are named by ISO 3166-1 code, or ISO 3166-2 for the home nations (gb-eng,
gb-sct, gb-wls). To add a nation, fetch its `flags/4x3/<code>.svg` from the same version into this folder.
